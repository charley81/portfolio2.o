# Christopher Harley — Portfolio

A one-page portfolio for Christopher Harley, featuring an introduction, selected projects, and contact links. Built with Astro and styled with plain CSS.

## Requirements

- Node.js 22.23.4 or newer
- pnpm

## Getting started

```sh
pnpm install
pnpm astro dev --background
```

Open the URL reported by Astro (normally `http://localhost:4321`). Use `pnpm astro dev status`, `pnpm astro dev logs`, and `pnpm astro dev stop` to manage the background server.


To update the portfolio content or links, edit `src/data/portfolio.ts`.
